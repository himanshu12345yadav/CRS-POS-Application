### Customer Registration System - CRS

This is an open-source Customer Registration System (CRS) designed to manage student registrations, grading, fee payments, course managements and dashboards for professors, admin, and students. It is built on top of the Java platform and uses the MySQL database for data storage.

### Features

- Manage student registrations
- Handle grading and fee payments
- Dashboards for admin, professors, and students
- Uses Singleton Pattern , Factory Pattern , Command Pattern

### Installation

1.  Clone this repository
2.  Import the project into STS software
3.  Import the database schema into MySQL
4.  Run the project using STS software console

### Usage

Once the project is installed, you can use the following command to run it as a standalone:

```bash
java -jar CRS_JAR.jar
```
